### EXERCICE: wages
#### Consigne:
Appliquez les augmentations à la table des salaires
* si le département est "SALES" => 10% d'augmentation
* si le département est "HR" => 05% d'augmentation
* si le département est "IT" => 03% d'augmentation
* pour les autres (le CEO) => 0% d'augmentation

### EXERCICE: orders
#### Consigne:
Écrivez une requête SQL qui :
Sélectionne toutes les colonnes de la table orders
Ajoute une nouvelle colonne appelée order_category qui catégorise chaque commande selon son montant :
* 'Small' : pour les commandes dont le montant est strictement inférieur à 200€
* 'Medium' : pour les commandes dont le montant est entre 200€ (inclus) et 800€ (exclus)
* 'Large' : pour les commandes dont le montant est supérieur ou égal à 800€
